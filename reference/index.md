# Package index

## Description

- [`okapi-package`](https://rapidsurveys.io/okapi/reference/okapi.md)
  [`okapi`](https://rapidsurveys.io/okapi/reference/okapi.md) : Open
  Data Kit (ODK)-based Computer-assisted Personal Interview (CAPI) Tools

## ONA API - Setup

- [`ona_auth_password()`](https://rapidsurveys.io/okapi/reference/ona_auth_password.md)
  : Basic authentication to ONA with a username and password
- [`ona_auth_token()`](https://rapidsurveys.io/okapi/reference/ona_auth_token.md)
  : Basic authentication to ONA with API authentication token
- [`ona_configure()`](https://rapidsurveys.io/okapi/reference/ona_configure.md)
  : Configure HTTP headers

## ONA API - Data

- [`ona_data_get()`](https://rapidsurveys.io/okapi/reference/ona_data_get.md)
  : Retrieve specific dataset by form ID from specific user
- [`ona_data_list()`](https://rapidsurveys.io/okapi/reference/ona_data_list.md)
  : Retrieve list of datasets available to specific user

## ONA API - Forms

- [`ona_form_delete()`](https://rapidsurveys.io/okapi/reference/ona_form_delete.md)
  : Delete published form
- [`ona_form_list()`](https://rapidsurveys.io/okapi/reference/ona_form_list.md)
  : List published forms
- [`ona_form_publish()`](https://rapidsurveys.io/okapi/reference/ona_form_publish.md)
  : Publish XLSForm

## ONA API - Projects

- [`ona_project_delete()`](https://rapidsurveys.io/okapi/reference/ona_project_delete.md)

  : List projects
- [`ona_project_register()`](https://rapidsurveys.io/okapi/reference/ona_project_register.md)

- [`ona_project_share()`](https://rapidsurveys.io/okapi/reference/ona_project_share.md)
